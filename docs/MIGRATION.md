# V5 → V6 迁移记录

- 并列独立目录；没有复用 V5 环境或修改 V5 源码。
- uv 创建 .venv 和 uv.lock，包名 amr-graphon-control-v6，Python 3.12。
- 数学控制分离为任务分配、静态地图、本地观测和记忆、机器人本地路径、局部让行、期望速度、可执行输入安全优化、真实运动与区间审计。
- 目标槽位做初始化安全相容处理；V5 的跨角色目标有物理重叠，因此不宣称 V5/V6 的原始运输误差完全同条件可比。
- 物理碰撞阈值、请求的 CBF 裕量、槽位完成率、区域完成率分别记录。
- 固定 0.35 m 槽位完成阈值，没有通过放宽完成判据来提升结果。
- 路径和让行点不是官方目标；不会将机器人投影到安全区域或终点。
- 临时让行、有限观测记忆解决部署层的信息和通行问题，不被包装成全局能量单调性或全局分布估计的证明。
- 全局分布一致性估计、真实传感器误差界和可证明的备用恢复集合仍是独立后续研究问题。
